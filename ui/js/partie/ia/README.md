# Module IA

Module de prise de décision et d'automatisation des joueurs robots (ordinateurs).

- `tactique.js` : Choix tactique des couleurs de joker et cibles pour l'effet du 7.
- `decision.js` : Évaluation du meilleur coup valide (signaler, contester, uno, jouer carte, piocher).
- `agent.js` : Boucle réactive de l'agent bot avec temporisation naturelle.
- `groupe.js` : Gestionnaire de connexions de robots pour l'hôte de la salle.
